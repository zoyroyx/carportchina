# Данные предпросмотра

Основной сайт читает `offers.json` и `company.json` при старте сервера. После изменения перезапустить сервер. Это файловый источник для текущего этапа, не CMS и не автоматический импорт.

## Автомобили

`offers.json` содержит массив по `packages/contracts/offers.ts`. На 03.11.2026 добавлены Changan Qiyuan A06, Geely Monjaro и Geely Galaxy M7 из пользовательского экспорта за 01.11.2026; Ferrari исключена. Не копировать тестовые записи в основной источник.

Обязательные поля: `id`, `slug`, `title`, `brand`, `publication`, `registrationMarket`, `priceKind`, `amountMinor`, `currency`, `validUntil`, `fullCostsConfirmed`, `termsApproved`, `estimateBasis`, `vatConfirmed`, `image`.

- `publication`: `draft`, `published` или `archived`. Это редакционные состояния, не категории поставки.
- ID и slug уникальны. Slug — латиница в нижнем регистре, цифры и дефисы. Публичный маршрут `/cars/{slug}/`.
- Публикационные проверки допускают только российский сценарий `RF`. Другие рынки не смешиваются с общей ценой.
- `priceKind`: `fixed_total`, `estimate_total`, `on_request`. Сумма — строка целого количества копеек; валюта `RUB`. Для запроса цены сумма `null`. Для числовой цены обязательны корректный срок актуальности и подтверждённые условия/полный состав расходов; для оценки — основание.
- Просроченная цена заменяется на «Стоимость уточняется» и не попадает в бюджетный фильтр. НДС — по конкретному предложению, не обещание вычета.
- Дополнительно: `model`, `year`, `mileageKm`, `trim`, `description`, `seller`, `updatedAt`, `gallery: [{src, alt}]`, `specifications: [{label, value}]`, `priceIncludes`, `priceExcludes`, `documents` (последние три — массивы строк).
- Фотографии: локальный URL от `/` или HTTPS. Исполняемые/небезопасные схемы не выводятся. Рекомендуется локальное хранение разрешённых оригиналов с оптимизированными версиями.

Сервер валидирует схему и уникальность при старте. Запись с нарушением условий публикации не выводится, даже если имеет `published`; черновики и архив также не выдаются API карточки. Формат схемы проверяется строго, лишние поля предложения запрещены.

## Компания и доказательства

`company.json`: `contacts: null` до подтверждения. Заполненный объект требует `phone` в международном формате с `+`, `legalName`, `requisites`; необязательно `address`, `hours`, `messenger` (HTTPS).

`stories` — массив: `id`, `title`, `text`, `kind` (`delivery`, `service`, `team`), `image`, `imageAlt`, `approved`; необязательно `sourceUrl` (HTTPS) и `serviceSlug`. Выводятся только `approved: true`. Для услуги указать её точный slug. Это отметка согласования владельцем материалов, не автоматическая проверка правдивости.

Нет данных — нет выдуманных историй. Контакты при заполнении появляются на странице и в подвале, но сами по себе не включают серверный приём заявок.

## Проверка без публикации

`tests/fixtures/offers.json` — исключительно искусственные данные для QA. Изолированный сервер можно запускать с `PORT=4174` и `CARPORT_INVENTORY_FILE=tests/fixtures/offers.json`. Основной сервер4173 использует реальный источник с тремя предложениями. Не применять fixture при публичном размещении.

Событие `carport:journey` в браузере — локальный CustomEvent. Внешняя аналитика не подключена; содержание обращений не включается. `brief_preview`/`brief_download` означают только подготовку/скачивание, не получение заявки компанией.

## Импорт 03.11.2026

24 фотографии оптимизированы в WebP без обрезки: `public/photos/catalog/`. Соответствия оригиналам: `output/catalog-import/photo-manifest.json`. Фото здания (1) и Ferrari (26–34) не включены. Исходный экспорт не изменён.

`sourcePrice: {fromRub, date, note}` хранит исходную цену «от» отдельно от подтверждённой итоговой цены. Предложения остаются `on_request`, без выдуманного срока действия, подтверждения НДС или расходов. Исходные цены не участвуют в бюджетном фильтре и сортировке подтверждённых цен. `highlights` — краткие факты; `equipment` — группы опций; `photoNote` — пояснение к галерее. Название Galaxy M7 и характеристики сохранены по сообщению, независимо не проверялись. Фотографии демонстрируют разные исполнения, это указано на страницах.
