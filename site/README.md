# CarPort China

## Текущее состояние · 08.11.2026

Сайт опубликован на https://carportchina.ru/ через GitHub Actions и FTP. Исходники полного проекта: zoyroyx/carportchina, каталог `site/`. Деплой генерирует 36 HTML-страниц; локально сохраняется SSR-разработка. Подробнее: [docs/deployment.md](docs/deployment.md).

Сайт с каталогом из 19 предложений, живыми фильтрами, страницами услуг и отзывами клиентов. На главной и посадочных действует прелоадер по готовности первого экрана. На `/reviews/` размещены два видео и две фотографии, ссылки добавлены в шапку и мобильное меню. Подробности медиа, прелоадера и проверок: [docs/reviews-preloader.md](docs/reviews-preloader.md).

Ниже историческое описание первой сборки; сведения о пустом каталоге/иллюстрации hero устарели. CMS и приём заявок не подключены. Полный сайт опубликован 08.11.2026. Ранее опубликованная отдельная главная на GitHub Pages этой работой не обновлялась.

### SEO и будущий домен

Канонический адрес: `https://carportchina.ru`, без www. `apps/server/seo.ts` формирует уникальные title/description, canonical без параметров, Open Graph/Twitter, JSON-LD и `/sitemap.xml`. Фильтры каталога не индексируются; пустые контакты/выдачи и неподготовленные юридические документы исключены из sitemap.

`pnpm start` сам по себе оставляет preview закрытым (`noindex,nofollow`, robots Disallow). Для будущего публичного окружения запуска с `--production` передайте `CARPORT_PUBLIC_SITE=true` в окружение процесса. Значение в `.env.example` справочное: файл автоматически не загружается. Этот флаг только управляет индексацией, не включает отправку заявок и не означает готовность всего бизнеса к запуску.

На хостинге потребуется настроить DNS/TLS и HTTP→HTTPS на reverse proxy; www→без-www перенаправление уже есть в приложении, на proxy рекомендуется единый переход сразу к HTTPS без www. Не доверяйте произвольным forwarded-заголовкам. После реального развёртывания проверьте robots/HTTP-заголовки и отправьте `/sitemap.xml` в Google Search Console и Яндекс Вебмастер. DNS, SSL и кабинеты в этой локальной работе не менялись.

Семантика: Organization, WebSite, WebPage/CollectionPage, BreadcrumbList, Service, ItemList, Car. Исходные цены «от» не превращаются в Offer; Offer создаётся только для действующей подтверждённой фиксированной цены. Отзывы, рейтинг, наличие, адрес и телефон не выдумываются. Без подтверждённых обязательных данных не заявляется право на товарный rich result.

`node tmp/prepare-catalog-seo.mjs` пересобирает responsive фото 360/640, размеры `data/catalog-images.json`, favicon и social image после обновления исходных фото. Проверки: `pnpm test`, `pnpm typecheck`, `pnpm build`. Независимый отчёт: `output/seo-audit-2026-11-03/independent-audit.md`.

Первая локальная сборка по `TZ.md` v2 и `DESIGN.md`. Это начало реализации, не готовый публичный выпуск.

## Запуск

Node 24 (проверено на 24.15.0), pnpm 11.25.0. Все версии закреплены в package.json и pnpm-lock.yaml.

```sh
pnpm install --frozen-lockfile
pnpm dev
```

Открыть http://127.0.0.1:4173. Сервер по умолчанию слушает только loopback. Переменные PORT/HOST читаются из окружения процесса; `.env.example` служит справочником, автоматическая загрузка `.env` пока не включена.

```sh
pnpm typecheck
pnpm test
pnpm build
pnpm start
```

`start` обслуживает собранные client/server с Fastify. Перед запуском остановить dev на том же порту. Все команды запускать из корня проекта. Остановка — Ctrl+C.

## Что работает

- React + Vite, серверный HTML и гидратация, strict TypeScript.
- 16 основных статических страниц: главная, каталог, заказ, B2B, список услуг, 8 отдельных услуг, выдачи, компания, контакты. Дополнительно 2 временных документа и настоящая 404.
- Общие компоненты, локальный Golos Text, существующий PNG логотипа, светлая/тёмная/системная тема, мобильное меню, FAQ.
- GET-фильтры статуса/марки/НДС и честное пустое состояние каталога.
- Локальный предпросмотр запросов по сценариям. Персональные данные не запрашиваются; отправки, хранения и уведомления нет. Без JS форма отключена.
- Начало доменного контракта предложения: цена в копейках строкой, проверка RF и unit/model_offer, полноты итоговой цены, устаревания и счётчиков. Тестовые предложения существуют только в тестах.
- Предварительные read-only endpoints `/api/v1/public/offers`, `/counts`, `/settings`. Это ещё не полный контракт API ТЗ. Остальные API возвращают 503 и не принимают данные.
- `noindex`, robots Disallow, no-store, 404 и безопасная сериализация начальных данных.

Никаких вымышленных цен, автомобилей, отзывов или контактных данных нет. Юридические страницы пока не являются действующими документами.
